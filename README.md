# Egerton Connect

A community site for adults (18+) around Egerton University, built with plain HTML, CSS and JavaScript,
Supabase (accounts, database, photo storage, live chat) and hosted on Vercel.

Files: `index.html`, `style.css`, `app.js`, `legal.js`.
Database setup lives in Supabase (see `database-update.sql`, kept outside this folder).
